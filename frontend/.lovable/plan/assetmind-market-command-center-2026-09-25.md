# AssetMind Market Command Center

## Goal
Turn the blank home screen into the selected Market Command Center design for the core Explore workflow.

## Build
- Establish the locked Emerald Signal color system and Libre Baskerville / IBM Plex typography.
- Recreate the selected three-rail dashboard: navigation, filters, company results, and intelligence panels.
- Add realistic, clearly labeled demo company data for the 10 featured companies.
- Make search, sector/country/market-cap filters, sorting, watchlist toggles, and company selection work in the browser.
- Add responsive tablet and mobile layouts with collapsible navigation and filters.
- Add an interactive stock trend chart and useful empty states without implementing live financial or AI services.
- Set AssetMind-specific page metadata.

## Technical details
- Keep the existing TanStack Start application structure.
- Use semantic design tokens in the global stylesheet and Lucide icons for controls.
- Keep all data local and labeled as illustrative, matching the brief's Phase 1 frontend-only scope.
- Validate the rendered screen at desktop and mobile sizes and check the preview for errors.
